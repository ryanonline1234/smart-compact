A Claude Code plugin · v0.1.0

Compact without forgetting.

Checkpoint the session to disk, let it compact automatically, and rehydrate only when you choose, with the cost of rehydrating measured on disk before anything is wiped.

claude plugin marketplace add ryanonline1234/smart-compact

  1. 01 · Fill

    Context fills.

    51k tokens of system prompt, tools and memory are fixed. The conversation grows on top: 40k here, 91k in all.

  2. 02 · Save

    Checkpoint first.

    /smart-compact:save writes a checkpoint and measures every file its manifest lists, before anything is wiped.

  3. 03 · Compact

    Then compact.

    When the turn ends, the plugin runs /compact: 91k becomes 28k by the engine's count. Compaction puts the checkpoint back by itself.

  4. 04 · Rehydrate

    Rebuild if you want.

    Your call. /smart-compact:rehydrate re-reads the manifest: ≈14.3k estimated at save, 15.2k when it ran.

Measured, not assumed

Every token count is calibrated.

Seven files, each read in a turn of its own on a real model; the cost is the context growth across the read. Sonnet 5.5 and Opus 5.5 counted identically. The usual rules of thumb, 4 and 3.2 characters per token, undercount by 1.3 to 1.5 times.

Install

Two commands.

Requires Claude Code 2.1.309 or later with mods enabled, the default from 2.1.287. Tested in the desktop app and the CLI.

claude plugin marketplace add ryanonline1234/smart-compact
claude plugin install smart-compact@smart-compact
Commands
/smart-compact:save [budget]
Checkpoint, then compact when the turn ends. The budget caps a later rehydrate; default 150k.
/smart-compact:rehydrate [path] [budget]
Re-read the checkpoint and its manifest, skipping what is already in context. Only you can start it.
suggestAt
Context size, in tokens, at which the plugin suggests saving once. 0 means 60% of the window; −1 turns it off.
